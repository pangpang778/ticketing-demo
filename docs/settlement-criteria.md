# 判定口径（成文口径，随包分发）

> 来源：recon-diff-appeal-001 spec 第 2 节（accepted）。本系统**不做代码化比对**，
> 只承载「按该口径录入结论」这一动作（见 ticketing-escalate-001 spec 第 7 节）。

录入 `decide` 结论时，以下口径为判定依据：

1. **一切以结算单为准。** 申诉差异的判定基准是关联结算单（`--settlement`），
   不以订单页展示、口头承诺或其他单据为基准。
2. **运费计入。** 差异金额计算时运费计入结算金额，不剔除。
3. **跨月按原订单归属月。** 跨月结算的订单，差异归属原订单的归属月，
   不按结算单出账月归集。

`ticketing decide` 的 `--basis` 字段（`rejected` 必填）应引用上述口径说明判定依据，
用于回复商户。
